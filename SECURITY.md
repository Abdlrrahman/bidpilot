# Security Policy

## Supported Versions
Only the latest release of BidPilot is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
BidPilot is a static client-side demonstration platform that operates without backend servers, databases, or user accounts. It processes only synthetic demonstration data stored in local browser memory (`localStorage`).

If you discover a security issue or cross-site scripting (XSS) vector in the application shell, please report it responsibly by emailing:
**abdlrrahman.shibani@gmail.com**

Please do not disclose vulnerabilities publicly until a patch has been published.
