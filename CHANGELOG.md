# Changelog

All notable changes to BidPilot will be documented in this file.

## [1.0.0] - 2026-08-24
### Added
- Complete procurement opportunity control tower with bilingual interface (English LTR / Arabic RTL).
- 26 seeded deterministic synthetic requirements across 6 procurement domains.
- Pure TypeScript calculation engine for weighted compliance coverage, mandatory blocker overrides, and Expected Bid Value (EV).
- 3-scenario pricing waterfall (Conservative, Target, Competitive) with landed cost decomposition and buyer budget headroom analysis.
- Multi-factor explainable Go/No-Go decision scorecard with 6 weighted evaluation dimensions.
- Procurement milestone critical path timeline and auditable evidence document register with simulated hash verification.
- One-page print-ready executive summary brief and JSON/CSV import/export utilities.
- 100% Vitest unit test suite coverage for all scoring and commercial models.
- GitHub Actions CI and automated GitHub Pages deployment workflows.
